# Provider brand assets

Unmodified SVG brand marks from [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/8a1b2821bb768c484fe8da20c5e1838b6bf551a9/packages/static-svg/icons), pinned to revision `8a1b2821bb768c484fe8da20c5e1838b6bf551a9`.

The collection's MIT license is retained in LICENSE. Brand names and marks remain the property of their respective owners. These marks identify the service being configured.

Assets are served locally; API-key screens make no third-party image requests. Marks retain their original SVG colors. Tiles stay white in both themes except Kimi, whose white mark uses a dark tile. Unknown/custom services use a neutral server icon rather than an unrelated provider's logo.
