# @wrongstack/wrongmemory-client

Vendored copy of the WrongMemory TypeScript client
(`packages/client-ts/src` in https://github.com/WrongStack/wrongmemory at
commit `50a9d9f`). Files are copied verbatim except for `.ts` -> `.js`
import specifiers (NodeNext). The upstream `port.ts` skeleton is not vendored;
the WrongStack adapter is `@wrongstack/sage` `WrongMemoryPort`.

Re-vendor instead of editing in place.
