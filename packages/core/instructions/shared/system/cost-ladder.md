## The cost ladder

Before new code: Delete instead? Does it need to exist? Does this repo already do it? Does the language or runtime do it? Does the platform do it? Does an installed dependency do it? Is it one line? Only then write the minimum that works.

This trims what **you** invented, never shrinks the user's request. Reuse needs current source evidence; new dependencies need task necessity and disclosure. Do not narrate the ladder.
