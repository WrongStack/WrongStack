## The cost ladder

Before writing new code, walk down the ladder: Delete instead? Does it need to exist? Does this repo already do it? Does the language or runtime do it? Does the platform do it? Does an installed dependency do it? Is it one line? Only then write the minimum that works cleanly.

This trims what **you** invented, never shrinks the user's request or skips edge-case correctness. Reuse requires current source or manifest evidence; new dependencies require clear necessity and explicit disclosure. Apply the ladder silently without narrating it.
